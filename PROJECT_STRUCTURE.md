# Bottle Cap Detection All - Project Structure

This file is a quick map of the project folders and important outputs.

## Main Folders

| Folder | Purpose |
| --- | --- |
| `DataPreparation/` | Raw/working data preparation files, auto-label script, and external test images. |
| `Trainandrun/` | YOLO training scripts, trained runs, experiment outputs, weights, and prediction scripts. |
| `Report/` | Final report, presentation, report assets, and generator scripts. |
| `_cache/` | Python cache/temp files and extracted PDF text kept away from the main workflow. |

## Data

| Path | Purpose |
| --- | --- |
| `DataPreparation/DATA bottle_cap/` | Original class-folder dataset used for Grounding DINO auto-labeling. |
| `Trainandrun/Data label from roboflow/` | Final YOLOv8 dataset exported/checked with Roboflow. |
| `DataPreparation/For_Test/` | External test images used for manual model checking. |
| `DataPreparation/For_Test_Predictions/` | Prediction images generated by the selected final model. |

## Training and Testing Scripts

| File | Purpose |
| --- | --- |
| `DataPreparation/auto_label.py` | Auto-label images with Grounding DINO prompts. |
| `Trainandrun/train_yolo.py` | Baseline YOLOv8 training script. |
| `Trainandrun/hyperparam_compare.py` | Hyperparameter comparison for batch size, epoch, and learning rate. |
| `Trainandrun/augmentation_compare.py` | YOLO augmentation policy comparison. |
| `Trainandrun/test_augmentation_weights.py` | Tests every augmentation best.pt weight on the same image set. |
| `Trainandrun/predict.py` | Main inference script using the selected final model. |

## Experiment Outputs

| Path | Purpose |
| --- | --- |
| `Trainandrun/runs/bottle_cap/` | Original baseline training run. |
| `Trainandrun/yolo_hyperparam_output/select_batchsize+epoch/` | Batch size and epoch comparison results. |
| `Trainandrun/yolo_hyperparam_output/select_LR/` | Learning-rate comparison results. |
| `Trainandrun/yolo_augmentation_output/aug_compare_20260512_181523/` | Augmentation comparison results. |
| `Trainandrun/augmentation_weight_test_results/` | External image tests for each augmentation weight. |

## Final Selected Model

| Item | Value |
| --- | --- |
| Model | `YOLOv8n` |
| Batch size | `8` |
| Epochs | `150` |
| Learning rate | `0.005` |
| Optimizer | `SGD` |
| Augmentation | `No Mosaic` |
| Weight | `Trainandrun/yolo_augmentation_output/aug_compare_20260512_181523/no_mosaic/weights/best.pt` |

## Final Documents

| File | Purpose |
| --- | --- |
| `Report/Bottle_Cap_Detection_Final_Report.docx` | Final written report. |
| `Report/Bottle_Cap_Detection_Final_Presentation.pptx` | Final presentation slides. |
| `Report/generate_bottle_cap_report.py` | Regenerates the Word report. |
| `Report/generate_bottle_cap_presentation.py` | Regenerates the PowerPoint presentation. |

## Notes

- Dataset folders, training output folders, and weight paths were not moved, because several scripts depend on their current locations.
- Cache and temporary files were moved into `_cache/` to keep the project root easier to read.
